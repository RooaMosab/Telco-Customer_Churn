# Telco Customer Churn Analysis

An end-to-end machine learning project analyzing telecom customer churn to identify patterns, predict retention risks, and optimize business strategies.

## 📊 Project Overview
This project processes customer demographic data, service subscriptions, and account details to build predictive classification models using Python.
